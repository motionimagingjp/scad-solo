# 現在の実装状況フィードバック(Claude Code → Claude.ai chat)

HANDOFF.mdと`scad-solo.zip`を確認しました。9/5時点のスナップショットから
分岐していて、Claude Codeセッション側では9/5〜9/11の間にかなり実装が
進んでいます。今後の設計検討の前提として、現状を共有します。

## 1. ボトムナビは4タブ構成から変更済み(AI相談・ソロ活タブは廃止)

`components/BottomNav.tsx`のコード内コメントより:

> AI相談タブは廃止した。モードボタンで大半の要望が指定できるようになり、
> 残る自由入力は「今夜の3軒」画面に置く方が「ハズレた直後に相談する」動線に
> 合うため。地図は自分で見渡したい人向けにナビへ戻してある。
> 「ソロ活」タブも廃止し、この枠は「ゲーム」に差し替えた。来店ログはマイページ
> からのリンクで十分たどり着け、常設タブにするほどではないと判断したため。

現在のナビ(4タブ): **おまかせ(ホーム) / 地図 / ゲーム / マイページ**
(`さがす/ソロ活/AI相談/マイページ`ではない)

## 2. ホーム画面は地図+ダミーピンではなく、実データ検索

`app/page.tsx`は現在地(または手動指定エリア)から近い順に、DBの実店舗
データをAPI(`/api/spots`)経由で取得し、**「今夜のおすすめ3軒」**として
即座に3軒提示する検索画面です(乱数抽選ではない)。気分モード(カウンター席・
立ち飲み・せんべろ・日本酒・ワイン・ビール・女性ひとり歓迎)で絞り込み可能。
「次の3軒」ボタンで距離順プールから2回まで送れます。

`MOCK_SPOT`のような固定ダミーは使っていません。

## 3. チェックイン後のスタンプ・記念日・ランクは実装済み(ただし別実装)

`lib/rank.ts`・`prisma/schema.prisma`の`UserAchievement`はHANDOFF.md記載の
ものと同名で存在しますが、`lib/stamps.ts`・`StampCard.tsx`・
`ChatFooterSection.tsx`は現行実装には存在しません(別のアプローチで
`components/AnniversaryBanner.tsx`と`app/logs/page.tsx`にまとめています)。

## 4. 実店舗データが大幅に拡充済み

Phase 0(194件、東京23区+近郊15駅)に加え、Phase 1以降でGemini/ChatGPTの
出力を1件ずつWebSearchで実在確認する運用を確立し、40駅以上・1,000件近い
データを個別検証の上で投入しています(詳細は`CLAUDE.md`参照)。この過程で
Phase 0データの一部が捏造(ハルシネーション)だったことが判明し、修正済みです。

## 5. ブランド表示名

ご提案の「Tokyo Solo Club」表示名は適用しました(`app/layout.tsx`・
`app/page.tsx`のヘッダー・`app/mypage/page.tsx`・`lib/data/about.ts`・
`lib/data/scadApps.ts`)。開発コード名(package.json・リポジトリ名)は
SCAD-SOLOのまま維持しています。

## 今後の設計検討をする場合のお願い

Claude Codeセッション側の最新状態を都度共有しないと、今回のように
数日分の実装差分が生まれてしまいます。UI/UX方針を変更する場合は、
GitHubリポジトリ(`motionimagingjp/scad-solo`, `main`ブランチ)の
最新コミットログか`CLAUDE.md`を先に確認してから設計を検討いただけると
助かります。
