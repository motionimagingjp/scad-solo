# Geminiへのフィードバック文面(店名使い回し改善依頼)

以下をそのままGeminiに貼り付けてください。

---

前回、東京駅・神田駅・赤羽駅・品川駅の一人飲み店を検索してもらいましたが、
複数の駅で**同じ店名パターンを駅名だけ差し替えて使い回している**ことが
判明しました。実際に機械チェックした結果です:

- 「立ち呑み 魚金 ○○店」→ 東京駅・品川駅の両方に出現
- 「○○ 魚菜 割烹 魚市」→ 東京駅・品川駅・赤羽駅の3駅に出現
- 「○○ 昭和大衆酒場 呑処」→ 東京駅・品川駅・赤羽駅の3駅に出現
- 「手打蕎麦 満留賀 ○○店」→ 東京駅・品川駅に出現
- 「立ち呑み もつ焼き カドクラ ○○店」→ 東京駅・品川駅に出現
- 「ビストロ イル・ソーレ ○○」→ 東京駅・品川駅に出現
- 「Bar Oak ○○」→ 赤羽駅・品川駅に出現
- 「比内地鶏専門店 鶏びあ」「博多やさい串巻き 鳴門」「立ち呑み 煮込み じんざえもん」
  → これらは前回(Phase 0)の収集でも同じ店名が別駅に出現していた、
  **既知の使い回しパターン**です

これは実在しない店を作ってしまっている(ハルシネーション)可能性が高いです。
今後の検索では、以下を徹底してください:

1. **1駅ずつ、完全に独立したセッションのつもりで検索し直してください。**
   前の駅で見つけた店名・似た店名・同じテンプレート(「○○ 昭和大衆酒場」
   「○○ 魚菜 割烹 魚市」のような、駅名を差し替えれば別の駅にも通用しそうな
   汎用的すぎる名前)は、**その駅で本当に実在すると個別に確認できない限り、
   絶対に使わないでください**
2. 店名を思い出せない・確証が持てない場合は、無理に埋めずその枠を空けてください。
   15件のノルマより「実在確認できた店だけ」を優先します
3. 出典URL(食べログ・Googleマップ・個人ブログ等)は、**その店・その駅の
   ページを実際に開いて確認したものだけ**を書いてください。それっぽいURLを
   推測で作らないでください
4. 「エノテカ」「常陸野ブルーイング」のような全国チェーン・多店舗ブランドは、
   個人店ではないので対象外です(既存ルール通り)
5. 迷ったら載せない。件数が少なくても構いません

対象駅: (再検索してほしい駅名をここに書く。例: 東京駅、品川駅)

出力フォーマットは前回と同じです(name/address/nearestStation/tagline/
subCategories/hasCounterSeat/senberoAvailable/soloFriendliness/sourceNote)。
