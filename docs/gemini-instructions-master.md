# SCAD-SOLO 店舗データ収集 指示書(汎用版)

このチャットでは **[ここに駅名を1つだけ入れる]** 駅の一人飲みしやすい店を
**[目標件数]件**検索してください。他の駅の情報とは絶対に混ぜないでください
(1駅=1チャットで完全に独立して検索する)。

## 対象条件

- 対象駅から**徒歩10分以内**(駅から離れた別エリアの店を「最寄り駅」として
  紛れ込ませないこと。下記「失敗パターン6」を必ず読むこと)
- 実在し、**現在も営業している店**(閉店店舗は不可)
- 個人店・ローカルな名店を優先(大手チェーン・同一都道府県に5店舗以上ある
  ブランドは除外)
- ひとり客が入りやすい店(カウンター席がある、立ち飲み、せんべろ系など)

## ⚠️ 最重要ルール: 検索で実在確認できない店は出力しない

直近のテストで、提出された店の**大半が「そのような名前・住所の店を検索しても
一切見つからない」**という結果でした(ある駅では28件中0件が実在確認できた
だけでした)。これは、記憶や推測だけで「いかにもありそうな店名・住所」を
作文してしまっていることが原因と考えられます。

**店を1件出力する前に、必ずWeb検索で「店名+駅名」または「店名+住所」を
実際に検索し、独立した情報源(公式サイト・食べログ・ぐるなび・Retty・
ニュース記事・個人ブログ等)でその店の存在を確認してください。検索しても
何も出てこない場合は、その店を出力しないでください。** 件数が目標に届かな
くても構いません。存在しない店を1件出すより、確実な店を5件出す方が価値が
あります。

## これまでに実際に起きた失敗パターン(必読)

### 1. 実在する店の名前を変えてしまう
出典URLは存在するのに、店名だけ微妙に変わっているケースが多発しました。
- 「三兵 we-stand」→ 実在するのは「**三兵酒店**」(同じ住所)
- 「鯉とうなぎの将軍」→ 実在するのは「**鯉とうなぎのまるます家**」
- 「赤羽の関所」→ 実在するのは「**やきとん大王 赤羽店**」

**対策:** 店名単体でもう一度検索し、住所・業態が一致する独立したページが
実際に見つかることを確認する。似た名前の実在店がヒットしたら、その正しい
名前を使う。

### 2. tabelogの数字IDが無関係の別店舗を指す(失敗率100%で発生済み)
店名・住所は正しいのに、`tabelog.com`のURL(数字ID)を開くと**全く無関係の
別の店**(閉店済み含む)になっているケースが繰り返し発生しました。
**このため、tabelog形式のURLは使わないでください。**(下記sourceNoteの
ルール参照)

### 3. 出典URLそのものの捏造
`1000bero.net`の実際のURLは`https://1000bero.net/restaurant-646/`のような
**数字IDのみ**です。`restaurant-駅名-店名`のような駅名・店名入りのslug形式
は存在しません。URLを作文しないこと。

### 4. 閉店した店を現役として出す
検索結果に「閉店」「【閉店】」の表記がないか必ず確認してください。チェーン
の場合、対象駅の支店だけ閉店していて他の支店だけ残っている、ということも
あります(実例: 三州屋は最盛期から縮小し現在4店舗のみ。錦糸町店は現存せず)。

### 5. チェーン・複数店舗ブランドの見落とし
ブランド名で検索し、他エリアにも同名店が複数(5店舗以上)あるようなら対象外
です(実例: 紅とん、銀座ライオン、馬力、Craft Beer Market)。

### 6. 実在する店だが、最寄り駅が全く違う(新パターン・重大)
店自体は実在し営業中なのに、対象駅から数km離れた別エリアの店を「最寄り駅は
〇〇駅」として提出してくるケースがありました。
- 「かねます」(中央区勝どき)→ 正しい最寄り駅は**勝どき駅**、東京駅ではない
- 「もつ焼 宇ち多゛」(葛飾区立石)→ 正しい最寄り駅は**京成立石駅**
- 「酒場 富士屋本店」(渋谷区桜丘町)→ 正しい最寄り駅は**渋谷駅**

**対策:** 住所の区・町名が対象駅の徒歩圏内(同じ駅前エリア)と一致しているか
必ず確認する。有名店だからといって、対象駅の近くにあるとは限らない。

### 7. 住所の丁目・番地がずれている
店名・駅は合っているのに、住所の丁目や番地が実際と異なるケースが複数見つ
かっています。番地まで検索結果と突き合わせて確認してください。

## ⚠️ sourceNoteの運用ルール

- **tabelog形式のURLは使わない**(失敗パターン2の理由により)
- ぐるなび・Retty・公式サイト・個人ブログなど、実際に開いて内容を確認した
  URLがあればそれを使う
- 確証が持てるURLがない場合は`sourceNote`を**空文字("")のままでよい**
  (任意項目です)
- URLを推測・作文することは絶対に禁止です

## 出力フォーマット

```json
[
  {
    "name": "店名(正式名称、出典ページの表記そのまま)",
    "address": "住所(番地まで正確に。ビル名は省略可)",
    "nearestStation": "[対象駅名]",
    "tagline": "一言の推し文(20〜30字程度、誇張・創作しない)",
    "subCategories": ["立ち飲み", "日本酒", "ワイン", "ビール", "女性ひとり歓迎"から該当するものだけ],
    "hasCounterSeat": true,
    "senberoAvailable": true,
    "soloFriendliness": 8,
    "sourceNote": "実際に開いて確認したURL(tabelogは避ける。確証がなければ空文字)"
  }
]
```

JSON配列のみを出力し、前後に説明文を付けないでください。

## 最後に: 精度が最優先

**件数を埋めることより、実在確認が取れることを優先してください。** 検索して
確認できなかった店は出力しないでください。これまでの実績では、しっかり
Web検索で裏取りされた駅(例: 中野駅、神田駅)では15件中13〜14件が実在
確認できましたが、裏取りが甘いとみられる駅では提出全体の0〜1割しか実在
確認できませんでした。**必ず1件ずつ検索してから出力する**、という手順を
徹底してください。
