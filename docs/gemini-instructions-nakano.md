# SCAD-SOLO 店舗データ収集 指示書 — 中野駅

中野駅周辺の一人飲みしやすい店を**15件**検索してください。
新しいチャット(このチャットのみ)で、他の駅の情報と混ぜずに検索してください。

## 対象条件

- 中野駅から徒歩圏内(目安10分以内)
- 実在し、**現在も営業している店**(閉店店舗は不可)
- 個人店・ローカルな名店を優先(大手チェーン・同一都道府県に5店舗以上あるブランドは除外)
- ひとり客が入りやすい店(カウンター席がある、立ち飲み、せんべろ系など)

## 必読: 過去に実際に起きた失敗パターン

過去の提出データを1件ずつWebSearchで裏取りしたところ、以下の問題が繰り返し見つかりました。**同じ失敗をしないよう、店名を出す前に必ず個別に検索して裏取りしてください。**

### 1. 実在する店の名前を変えてしまう(最多の失敗パターン)
出典URLは存在するのに、店名だけ微妙に変わっているケースが多発しました。
- 「三兵 we-stand」→ 実在するのは「**三兵酒店**」(同じ住所)
- 「鯉とうなぎの将軍」→ 実在するのは「**鯉とうなぎのまるます家**」
- 「赤羽の関所」→ 実在するのは「**やきとん大王 赤羽店**」

**対策:** 店名単体でもう一度検索し、住所・業態が一致する独立したページが実際に見つかることを確認する。似た名前の実在店がヒットしたら、その正しい名前を使う。

### 2. tabelogの数字IDが無関係の別店舗を指す(失敗率100%・最重要)
店名・住所は正しいのに、`tabelog.com`のURL(数字ID)を開くと**全く無関係の別の店**(閉店済み含む)になっているケースが、直近の提出で15件中15件発生しました。
**このため、tabelog形式のURLは使わないでください。**

### 3. 出典URLそのものの捏造
`1000bero.net`の実際のURLは`https://1000bero.net/restaurant-646/`のような**数字IDのみ**です。`restaurant-nakano-xxx`のような駅名入りのslug形式は存在しません。

### 4. 閉店した店を現役として出す
検索結果に「閉店」「【閉店】」の表記がないか必ず確認してください。

### 5. チェーン・複数店舗ブランドの見落とし
ブランド名で検索し、他エリアにも同名店が複数(5店舗以上)あるようなら対象外です。

## ⚠️ sourceNoteの運用ルール(変更済み)

- **tabelog形式のURLは使わない**(上記の理由により)
- ぐるなび・Retty・公式サイト・個人ブログなど、実際に開いて内容を確認したURLがあればそれを使う
- 確証が持てるURLがない場合は`sourceNote`を**空文字("")のままでよい**(任意項目です)
- URLを推測・作文することは絶対に禁止です

**件数を埋めることより、実在確認が取れることを優先してください。** 確証が持てない店は無理に埋めず、15件に届かなくても構いません。

## 出力フォーマット

```json
[
  {
    "name": "店名(正式名称、出典ページの表記そのまま)",
    "address": "住所(番地まで正確に。ビル名は省略可)",
    "nearestStation": "中野駅",
    "tagline": "一言の推し文(20〜30字程度、誇張・創作しない)",
    "subCategories": ["立ち飲み", "日本酒", "ワイン", "ビール", "女性ひとり歓迎"から該当するものだけ],
    "hasCounterSeat": true,
    "senberoAvailable": true,
    "soloFriendliness": 8,
    "sourceNote": "実際に開いて確認したURL(tabelogは避ける。確証がなければ空文字)"
  }
]
```

JSON配列のみを出力し、前後に説明文を付けないでください。
