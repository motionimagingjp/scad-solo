## これまでに実際に起きた失敗パターン(重要・必読)

過去の提出データを1件ずつWebSearchで裏取りしたところ、以下の問題が繰り返し見つかりました。

### 1. 実在する店の名前を変えてしまう(最多の失敗パターン)
出典URLは存在するのに、店名だけ微妙に変わっているケースが多発しました。
- 「三兵 we-stand」→ 実在するのは「**三兵酒店**」(同じ住所)
- 「鯉とうなぎの将軍」→ 実在するのは「**鯉とうなぎのまるます家**」(同じ赤羽・同じコンセプト)
- 「大衆酒場 渡なべ」→ 高円寺には「なんたもんだ」等は実在するが「渡なべ」は確認できず
- 「赤羽の関所」→ 実在するのは「**やきとん大王 赤羽店**」
- 「食道園」(有楽町ガード下のもつ焼き店として提出)→ 実際の「食道園」は系統の違う老舗焼肉店で、ガード下もつ焼き店ではない

**対策:** 店名を出す前に、その店名単体でもう一度検索し、住所・業態が一致する独立したページ(公式サイト・食べログ・せんべろnet等)が実際に見つかることを確認してください。似た名前の実在店がヒットした場合は、その実在店の正しい名前を使ってください。

### 2. 出典URLが捏造されている
`1000bero.net`の実際のURLは`https://1000bero.net/restaurant-646/`のような**数字IDのみ**です。
`https://1000bero.net/restaurant-kanda-uosho/`のような駅名入りのURL形式は存在しません。
**URLを作文しないでください。実際にそのページを開いて内容を確認してから、正しいURLを貼ってください。**

### 3. 閉店した店を現役として出す
「ドラム缶 神田店」は閉店済みでしたが、営業中として提出されていました。検索結果に
「閉店」「【閉店】」の表記がないか必ず確認してください。

### 4. チェーン・複数店舗ブランドの見落とし
「常陸野ブルーイング」「エノテカ」のような、個人店に見えないが実は多店舗ブランドの店が
混ざっていました。ブランド名で検索し、他エリアにも同名店が複数あるようなら対象外です。
(実例: 有楽町駅で提出された「紅とん 国際フォーラム前店」都内10店舗以上、
「銀座ライオン 銀座インズ店」都内19店舗・全国33店舗)

### 5. 店名・住所は合っているのに、tabelogのIDだけが別の店を指す(最頻出・致命的)
有楽町駅の提出15件全て(2バッチ合計)で見つかった問題です。店名も住所も実在の店と
一致しているのに、貼られていた`tabelog.com`のURL(数字ID部分)を開くと**全く無関係の
別の店**(閉店済み店舗を含む)になっていました。URL全体を作文する(パターン2)よりも
巧妙で、一見すると出典があるように見えてしまいます。**この失敗率が100%だったため、
下記の通り運用ルールを変更しました。**

## ⚠️ sourceNoteの運用変更(重要)

tabelogの数字IDを正確に再現するのは困難なことが分かったため、**tabelog形式のURLを
無理に作らないでください。** 代わりに以下のいずれかにしてください。

- 公式サイト・食べログ以外の情報源(ぐるなび、Retty、個人ブログ、ニュース記事など)の
  実際に開いたURLがあればそれを使う
- 該当ページを開かずに確度の高いURLを提示することしかできない場合は、
  `sourceNote`を**空欄のままにする**(このフィールドは任意項目です)
- その代わり、`tagline`や本文の中でURLを作文で埋めることも禁止です

**`sourceNote`があることよりも、`name`・`address`・`nearestStation`が正確で、
実在・営業中であることの方が重要です。** 迷ったらURLは空欄にしてください。

## 基本ルール(継続)

- 実在し、現在も営業している店だけ(閉店店舗は不可)
- 個人店・ローカルな名店を優先(大手チェーン・同一都道府県に5店舗以上あるブランドは除外)
- 同じ店名パターンを駅名だけ差し替えて複数駅で使い回さない(1駅ごとに完全に独立して検索)
- カウンター席の有無、ソロ飲みへの向き不向きも確認する

## 出力フォーマット(変更なし)

```json
[
  {
    "name": "店名(正式名称、出典ページの表記そのまま)",
    "address": "住所(番地まで正確に)",
    "nearestStation": "駅名のみ(例: 中野駅。「徒歩3分」等の補足は書かない)",
    "tagline": "一言の推し文(20〜30字程度、誇張・創作しない)",
    "subCategories": ["立ち飲み", "日本酒", "ワイン", "ビール", "女性ひとり歓迎"から該当するものだけ],
    "hasCounterSeat": true,
    "senberoAvailable": true,
    "soloFriendliness": 8,
    "sourceNote": "実際に開いて確認した出典URL(tabelogは避ける。確証がなければ空文字でよい)"
  }
]
```

駅ごとに新しいチャット(セッション)で検索するのがおすすめです。1つのチャットに複数駅を
まとめると、店名の使い回しが起きやすいためです。
