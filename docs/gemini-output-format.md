# SCAD-SOLO 店舗データ 出力フォーマット指示書

Geminiに店舗候補を検索させる際は、この形式のJSON配列で出力するよう指示してください。

## 出力形式

```json
[
  {
    "name": "店名(正式名称、出典ページの表記そのまま)",
    "address": "住所(番地まで正確に。ビル名は省略可)",
    "nearestStation": "最寄り駅名のみ(例: 中野駅。「徒歩3分」等の補足は書かない)",
    "tagline": "一言の推し文(20〜30字程度、誇張・創作しない)",
    "subCategories": ["立ち飲み", "日本酒", "ワイン", "ビール", "女性ひとり歓迎"],
    "hasCounterSeat": true,
    "senberoAvailable": true,
    "soloFriendliness": 8,
    "sourceNote": "実際に開いて確認した出典URL(tabelogは避ける。確証がなければ空文字でよい)"
  }
]
```

## フィールド説明

| フィールド | 必須 | 型 | 説明 |
|---|---|---|---|
| `name` | ○ | string | 店名。出典ページの表記のまま。独自にリネーム・意訳しない |
| `address` | ○ | string | 番地まで正確な住所。ビル名を含めるとジオコーディングが失敗することがあるため、失敗する場合は番地までに簡略化する |
| `nearestStation` | ○ | string | 「〇〇駅」の形式のみ。所要時間・徒歩分数などの補足は書かない |
| `tagline` | 任意 | string | 20〜30字程度のひとこと紹介。誇張・創作表現は禁止、出典ページの事実に基づくこと |
| `subCategories` | 任意 | string[] | 「立ち飲み」「日本酒」「ワイン」「ビール」「女性ひとり歓迎」から該当するものだけを選ぶ(この5種類以外は使わない) |
| `hasCounterSeat` | 任意 | boolean | カウンター席の有無(デフォルト`true`)。出典で確認できた場合のみ明記、不明ならフィールド自体を省略可 |
| `senberoAvailable` | 任意 | boolean | 「せんべろ」(1000円前後で飲める)対応かどうか |
| `soloFriendliness` | 任意 | number | ひとり客への向き不向き、1〜10の整数(高いほど歓迎) |
| `sourceNote` | 任意 | string | 実際にそのページを開いて内容を確認した出典URL。**tabelog.comのURLは避けること**(数字IDを正確に再現できず、無関係な別店舗を指すケースが100%の頻度で発生した実績あり)。ぐるなび・Retty・公式サイト等の実際に開いたURLを優先し、確証がなければ空文字にする。URLを推測・作文しない(既知の失敗例: `1000bero.net`は`restaurant-646`のような数字IDのみのURLで、`restaurant-店名`のようなslug形式は存在しない) |

## 出力ルール

- JSON配列のみを出力する。前後に説明文やMarkdown装飾(```json以外)を付けない
- 1店舗1オブジェクト。件数の水増しのための重複・類似店は禁止
- 実在しない店・閉店済みの店は出力しない(確証が持てない場合はそもそも含めない)
